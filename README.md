# lab-inbox · 实验收件箱

小前端、小工具、小游戏等一次性实验代码的存档库。不占聊天侧边栏，统一存这里：以后好找，其他 Agent（GPT / Gemini / Claude / Codex / 本地 Agent）也能直接读、直接改。

## 结构

- `experiments/<日期>-<主题>/` — 每个实验一个文件夹，自带一份 `NOTES.md` 说明来历、做法和结论
- 同一主题的多方产物放同一文件夹并排对比（如不同模型各做一版）

## 约定

- 文件尽量自包含（单文件 HTML 优先），打开就能跑
- 实验做完把结论写回该文件夹的 `NOTES.md`，不只存代码
- 这里是实验区，不是产品仓：可以糙，可以废弃，废弃的在 NOTES 里标明即可
