# 诊断标签表（症状 → 处方方向）

| 标签 | 症状（模糊图上可见） | 处方方向 |
|---|---|---|
| 双主角 | 两个同级大块争夺第一落点 | 降一个，或拆页 |
| CTA无主题 | 唯一显著块在底部，是个按钮，主题无声 | 先补主题锚点（大图/大标题），再把 CTA 并进锚点区 |
| 装饰抢焦点 | 显著块是横幅/装饰图，与任务无关 | 删或压暗装饰，显著度让给内容 |
| 全员同权重 | 没有任何显著块，全页均匀灰 | 按主次表逐级拉开：先定唯一主角 |
| 只靠颜色分层 | 彩色模糊图有主次，灰度图全平 | 用明度差重做层级，颜色只作辅助 |
| 小亮点噪声 | 次要区在模糊后仍是一堆小亮点 | 次要元素成组降级：去底色、变灰、合并容器 |
| 分组溶解 | 缩略图里分不出组块 | 组间留白 ≥ 组内 2 倍，减少容器数量 |
